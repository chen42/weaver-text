## Handling rules

- Keep local source documents unchanged.
- Keep local copies of restricted documents for the user's own use; do not redistribute them through a public repository, a third-party upload, or sharing outside the user's workspace.
- Record replacements and amendments as new inventory entries.
- Trace extracted requirements to a source ID and a page, section, or URL anchor.
- Use the same record fields for `references/papers/README.md`, numbering papers P-001, P-002, and so on.
- Follow `08_source_capture_and_provenance.md` for capture formats, checksums, and the archive fallback when a URL-only record is used.
